# Contributing Guidelines

1. **Strict Type Hints**: 100% strict type hints verified by `mypy src tests`.
2. **Linting & Formatting**: Follow `ruff format` and `ruff check` (max line length 100).
3. **Security Analysis**: Zero high/medium findings via `bandit -r src`.
4. **Test Coverage**: Maintain $\ge 90\%$ branch test coverage.
